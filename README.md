## Роли
- OWNER — полный контроль
- DEPUTY — может выдавать ADMIN / MODERATOR / HELPER
- ADMIN — бан/разбан, очистка варнов, муты, варны
- MODERATOR — мут/размут, варны
- HELPER — варны
- MEMBER — обычный участник

Защита иерархии:
нижняя роль не может наказать равную или более высокую.

## Команды
### Для всех
- `/rules`
- `/role`
- `/staff`
- `/warns`
- `/help`

### HELPER+
Ответом на сообщение:
- `/warn причина`

### MODERATOR+
- `/mute 30m причина`
- `/mute 2h причина`
- `/unmute`

### ADMIN+
- `/ban причина`
- `/clearwarns`
- `/unban 123456789`

### DEPUTY+
- `/setrole helper`
- `/setrole moderator`
- `/setrole admin`
- `/demote`

### Только OWNER
- `/setrole deputy`

## Автоочистка
Когда админ использует `/warn`, `/mute`, `/ban`, `/unmute`,
`/clearwarns`, `/setrole`, `/demote` и т.д.:

1. команда администратора удаляется через 20 секунд;
2. ответ бота тоже удаляется через 20 секунд.

Автоматические сообщения AutoMod также очищаются через 20 секунд.

## Старые сообщения
Бот не должен трогать историю чата:
- при добавлении в группу сохраняется время подключения;
- сообщения, созданные раньше этого времени, игнорируются;
- при перезапуске бот запускается с `drop_pending_updates=True`,
  поэтому накопившиеся старые Telegram updates после офлайна не модерируются.

## Ссылки
- TikTok разрешён.
- Другие ссылки/реклама удаляются.
- За ссылку нет мута и нет варна.

## Автомод
- мат -> удаление + варн;
- оскорбление -> удаление + варн;
- 3 варна -> мут 5 минут;
- оскорбление родителей/семьи -> сразу мут 2 часа;
- уведомление показывает причину и кто выдал наказание.

## Telegram настройки
1. Создай бота в BotFather.
2. `/setprivacy` -> выбери бота -> `Disable`.
3. Добавь бота в группу как администратора.
4. Дай права:
   - Delete messages
   - Ban users
   - Restrict members

## Важно про базу
SQLite-файл `bot.db` подходит для старта.
Если Render пересоздаст файловую систему при новом деплое, роли/варны могут сброситься.
Для полностью постоянного хранения потом лучше подключить PostgreSQL или Persistent Disk.

## v4 — привязка к одной группе

Добавлена переменная `ALLOWED_CHAT_ID`.

- `0` = бот работает во всех группах.
- ID группы = бот работает только в этой группе.

Как настроить:
1. Отправь в нужной группе `/chatid`.
2. Скопируй ID вида `-1001234567890`.
3. Render → Environment: `ALLOWED_CHAT_ID=-1001234567890`
4. Save Changes → Deploy.
